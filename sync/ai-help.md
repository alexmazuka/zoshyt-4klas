# ШІ-помічник «Поясняйко» 🦉

На кожній сторінці уроку (`lesson.html`) є плаваюча кнопка 🦉 внизу праворуч — це «Поясняйко»,
чат-помічник, який пояснює матеріал уроку простими словами. Реалізовано в `js/ai-help.js`
(інтерфейс і промпт) + `js/ai-config.js` (лише адреса проксі, без секретів).

## Головне правило

У системний промпт жорстко закладено: Поясняйко **ніколи не дає готову відповідь** на вправу чи
домашнє завдання, навіть якщо дитина прямо просить або каже, що це дозволили батьки — натомість він
пояснює правило/спосіб міркування і ставить зустрічне запитання. Це обмеження на рівні промпту, а не
коду — 100%-ї гарантії немає (дуже наполеглива дитина теоретично може обійти), але для мети «навчити,
а не зробити за дитину» цього достатньо.

Контекст (який урок, який крок — теорія/практика/домашнє/підсумок, умови вправ **без відповідей**)
lesson.js передає автоматично через `AiHelp.setContext()`, тому дитині не треба нічого пояснювати —
Поясняйко вже знає, де вона зараз.

## Архітектура: чому проксі, а не ключ прямо в коді сайту

Перша версія тримала ключ OpenRouter/Gemini прямо у відкритому клієнтському коді (як `apiKey`
Firebase). Це **не спрацювало**: обидва провайдери мають автоматичне сканування публічних
GitHub-репозиторіїв (GitHub Secret Scanning Partner Program) і самі відкликають будь-який ключ, щойно
його виявляють опублікованим — за лічені хвилини, без попередження. Це їхній штатний захист від
витоку, обійти його неможливо (і не варто намагатись).

Тому зараз сайт не звертається до OpenRouter/Gemini напряму — він звертається до **власного
сервера-проксі** на Cloudflare Workers (безкоштовний план, 100 000 запитів/добу):

```
браузер дитини → Cloudflare Worker (тримає ключі як secrets) → OpenRouter (основний) → Gemini (резерв)
```

- **Worker:** `zoshyt-4klas-ai` в акаунті Cloudflare `Alex@matsuka.online` —
  [dash.cloudflare.com](https://dash.cloudflare.com/) → Workers & Pages → zoshyt-4klas-ai. Код —
  вкладка «Edit code» (редагується прямо в браузері, без CLI). URL —
  `https://zoshyt-4klas-ai.alex-f53.workers.dev/`, прописаний у `js/ai-config.js`.
- **Секрети Worker'а** (Settings → Variables and secrets, тип «Secret» — зашифровані, невидимі навіть
  власнику після збереження): `OPENROUTER_API_KEY` (обов'язковий), за бажання `GEMINI_API_KEY` (резерв,
  якщо не задано — Worker просто пропускає цей крок). Ці ключі ніколи не потрапляють у git.
- **OpenRouter:** ключ `zoshyt-4klas-worker`, модель `openrouter/free` (роутер сам обирає поточну
  безкоштовну модель — список у OpenRouter час від часу змінюється). Ліміт витрат **$1/місяць**
  виставлено в кабінеті OpenRouter (Settings → API Keys → цей ключ → Credit limit) — навіть у
  гіршому разі шкода обмежена цією сумою.
- **CORS:** Worker приймає запити лише з `https://alexmazuka.github.io` і локальних
  `http://localhost:876x` (список у `ALLOWED_ORIGINS` на початку коду Worker'а) — це м'яке обмеження
  (CORS перевіряє браузер, не сам сервер), реальний захист від зловживань — ліміт витрат вище.

## Приватність

На безкоштовному рівні і OpenRouter, і Google можуть використовувати текст запитів для покращення
власних сервісів (у Google це прямо прописано в умовах безкоштовного рівня Gemini API, включно з
можливим переглядом людьми-рев'юєрами). Для навчальних питань по уроку це прийнятний ризик, але варто
знати: повідомлення, які дитина пише Поясняйку, не є повністю приватними.

## Якщо ключ або Worker треба замінити

1. Новий ключ OpenRouter — [openrouter.ai/settings/keys](https://openrouter.ai/settings/keys) (не
   забути виставити Credit limit і Reset — інакше витрати необмежені).
2. Новий ключ Gemini — [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
3. Вставити в Cloudflare: Worker `zoshyt-4klas-ai` → Settings → Variables and secrets → редагувати
   `OPENROUTER_API_KEY`/`GEMINI_API_KEY` (тип «Secret») → зберегти (деплоїться автоматично).

Сам URL проксі (`js/ai-config.js`) міняти не треба, якщо Worker не перейменовувати.
