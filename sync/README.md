# Синхронізація прогресу між пристроями (Firebase)

Зошит використовує безкоштовний проєкт **Firebase Firestore**, щоб прогрес дитини був однаковим
одразу на кількох пристроях (наприклад, ноутбук дитини й телефон батьків) — оновлення приходять
в реальному часі, без ручного експорту/імпорту.

## Як це влаштовано

- Один Firestore-документ `families/{сімейний код}` містить увесь прогрес дитини (у тому самому
  форматі, що й файл резервної копії з кабінету батьків).
- Кожен пристрій, на якому введено той самий **сімейний код**, підписується на зміни цього
  документа (`onSnapshot`) і водночас надсилає туди власні зміни (з невеликою затримкою ~1,5 с).
- «Пароль» до даних сім'ї — сам код: 10 символів у форматі `XXXXX-XXXXX` (без цифр/букв, які легко
  переплутати — 0/O/1/I/L), який генерується випадково. Перебрати чи вгадати його на практиці
  неможливо. Правила безпеки Firestore ([`firestore.rules`](firestore.rules)) не вимагають окремого
  логіну — саме довжина й випадковість коду і є захистом, підхід той самий, що й у приватного
  посилання на Google-документ.
- Проєкт Firebase (`zoshyt-4klas`) уже створено й налаштовано — конфігурація лежить у
  [`../js/firebase-init.js`](../js/firebase-init.js). Значення там (`apiKey` тощо) — публічні
  ідентифікатори проєкту, а не секрет; вони лише кажуть застосунку, до якої бази звертатися.

## Як користуватися (у кабінеті батьків)

1. На пристрої дитини (або будь-якому першому пристрої): **Батькам → Налаштування → «Створити
   сімейний код»**. З'явиться код виду `AB3K7-9XQPZ`.
2. На іншому пристрої батьків: **Батькам → Налаштування → «Скопіювати посилання для кабінету
   батьків»** на ПЕРШОМУ пристрої → надішліть собі це посилання (Messages, AirDrop, email) →
   відкрийте його на другому пристрої. Він одразу приєднається до тієї самої сім'ї без введення
   коду вручну. Так само є посилання «для пристрою дитини», якщо потрібно налаштувати ще один
   дитячий пристрій.
3. Альтернатива посиланню — ввести код вручну: **Налаштування → «Приєднатися за кодом»**.
4. Готово: тепер зміни на будь-якому підключеному пристрої (виконана вправа, здане домашнє,
   перевірка батьків) з'являються на решті пристроїв за секунди.

Кабінет батьків (розділ «Огляд» і «Налаштування») показує стан з'єднання (☁️✓ підключено,
☁️… підключення, ☁️! немає зв'язку) і час останнього оновлення.

## Якщо потрібно повністю відключити пристрій

**Батькам → Налаштування → «Відключити цей пристрій від сім'ї»** — прогрес НА ЦЬОМУ пристрої
залишається (локально), але він більше не отримує й не надсилає оновлення. Дані інших пристроїв
сім'ї не змінюються.

## Технічні деталі (для розробника/адміністратора проєкту)

- Firebase-проєкт створюється й налаштовується один раз через [Firebase Console](https://console.firebase.google.com/):
  Firestore Database (Standard edition, режим Native) + Web App. Отриманий конфіг вставляється в
  `js/firebase-init.js`.
- Правила безпеки публікуються у Firestore → вкладка Rules; актуальна версія продубльована тут, у
  [`firestore.rules`](firestore.rules), для довідки та якщо колись знадобиться `firebase deploy`.
- План безкоштовний (Spark): 50 000 читань і 20 000 записів на день — домашньому використанню
  цього більш ніж достатньо (типове навантаження — десятки записів на день).
- Резервна копія прогресу (кнопки «Експортувати / Імпортувати JSON» у кабінеті батьків, вкладка
  «Звіт») як і раніше працює незалежно від Firebase — корисно як додаткова підстраховка або для
  пристрою, який тимчасово офлайн.
