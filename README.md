# 📘 Робочий зошит — 4 клас, I семестр 2026/2027

Інтерактивний робочий зошит для **самостійного домашнього навчання** учня 4 класу за програмою НУШ
(Типова освітня програма О. Я. Савченко, Державний стандарт початкової освіти). Охоплює **всі 10 предметів**,
**385 уроків** за розкладом 25 год/тиждень з 1 вересня до 23 грудня 2026 (I і II чверті), з автоматичною
перевіркою вправ і **кабінетом батьків** для контролю кожного уроку й домашнього завдання.

🔗 **Сайт:** https://alexmazuka.github.io/zoshyt-4klas/

Кожен урок: **теорія** → **практика** (12 типів інтерактивних вправ, миттєва перевірка, дві спроби) →
**домашнє завдання** (з письмовою роботою для перевірки батьками) → **підсумок** (зірки, XP, рефлексія).

## Контроль для батьків

- Кабінет батьків (`parent.html`, доступ за PIN, який знає лише батько/мати — PIN зберігається на сайті лише як SHA-256 хеш і повідомляється окремо, поза інтерфейсом): прогрес по тижнях і предметах, кожна відповідь
  дитини, письмові домашні роботи з кнопками «Прийнято» / «Повернути з коментарем», журнал подій, прострочені уроки.
- Щотижневий звіт одним натисканням у Telegram або e-mail.
- Експорт / імпорт прогресу (JSON).
- Спільний прогрес між пристроями через «сімейний код» (Firebase Firestore, у реальному часі, без ручного оновлення):
  [sync/README.md](sync/README.md).

## Структура

```
index.html            головна: уроки на сьогодні, борги, прогрес
week.html?w=N         розклад тижня       subject.html?s=math   уроки предмета
lesson.html?id=…      урок                parent.html           кабінет батьків
achievements.html     нагороди            about.html            програма, календар, юридична довідка
data/calendar.json    структура семестру  data/subjects.json    предмети і розклад
data/plan/*.json      тематичні плани     data/plan.json        зібраний план (tools/build_plan.py)
data/lessons/<subj>/  уроки JSON          tools/validate.py     перевірка схеми уроків
js/, css/             рушій без залежностей і збірки
js/firebase-init.js   міст до Firebase SDK (сімейний код, синхронізація в реальному часі)
sync/firestore.rules  правила безпеки Firestore (для довідки, оригінал — у Firebase Console)
```

## Розробка

```bash
python3 -m http.server 8765          # локальний перегляд: http://localhost:8765
python3 tools/validate.py            # перевірити всі уроки
python3 tools/build_plan.py          # перезібрати data/plan.json після зміни планів або додавання уроків
```

Схема уроку та правила написання — в [AUTHORING.md](AUTHORING.md). Прогрес зберігається в `localStorage`
браузера; жодні дані не надсилаються нікуди без явного налаштування синхронізації.
