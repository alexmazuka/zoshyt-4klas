# Як писати уроки (схема JSON)

Кожен урок — окремий файл `data/lessons/<subject>/<id>.json`, де `id` береться з `data/plan.json`
(наприклад `math-w03-d1`). Файл — валідний JSON (UTF-8, без коментарів). Перевірка:
`python3 tools/validate.py data/lessons/math/math-w03-d1.json` (або без аргументів — усі файли).

Мова уроків — українська (крім англійської: там інструкції українською, матеріал англійською).
Звертання до учня — на «ти», дружньо, без сюсюкання. Учень — хлопчик 9–10 років, 4 клас,
навчається вдома самостійно; дорослий поруч не завжди, тому кожне пояснення має бути самодостатнім.

## Каркас файлу

```json
{
  "id": "math-w03-d1",
  "subject": "math",
  "title": "Письмове множення на одноцифрове число",
  "goal": "Сьогодні ти навчишся множити стовпчиком трицифрове число на одноцифрове.",
  "minutes": 35,
  "theory": [ ...блоки теорії... ],
  "exercises": [ ...4–8 вправ з автоматичною перевіркою... ],
  "homework": [ ...2–4 завдання, серед них 1 письмове або творче... ],
  "reflection": ["Що було найлегшим?", "Де ти помилився і чому?"]
}
```

- `id`, `subject`, `title` мають збігатися з `data/plan.json` (title можна злегка скоротити, але тема та сама).
- `minutes` — орієнтовний час на урок разом із практикою (25–45).
- `reflection` — 1–3 запитання для самооцінки (необов'язково).

## Блоки теорії (`theory`)

Порядок довільний, 3–8 блоків. Текст підтримує `**жирний**`, `*курсив*` і перенос рядка `\n`.

| type | поля | призначення |
|---|---|---|
| `p` | `text` | абзац пояснення |
| `rule` | `title`, `text` | правило / «Запам'ятай» у рамці |
| `example` | `title`?, `text` | розібраний приклад; для математики — запис обчислення покроково |
| `list` | `title`?, `items[]` | маркований список |
| `steps` | `title`?, `items[]` | нумерований алгоритм дій |
| `table` | `title`?, `head[]`, `rows[][]` | таблиця (класи й розряди, відмінки тощо) |
| `reading` | `title`, `author`?, `text`, `genre`? | великий текст для читання (абзаци через `\n\n`), є кнопка озвучення |
| `vocab` | `title`?, `items[{en, uk, ex?}]` | словник англійських слів з озвученням |
| `dialogue` | `title`?, `lines[{who, text}]`, `lang`? | діалог (англійська: `lang: "en"`) |
| `tip` | `text` | підказка, лайфхак |
| `image` | `emoji`, `caption` | «картинка» емодзі з підписом (зображень-файлів немає) |

## Вправи (`exercises`) і домашнє завдання (`homework`)

Одна вправа — об'єкт із полем `type`. Поле `q` — умова (обов'язкове для всіх, крім `truefalse`, де воно
необов'язкове). Необов'язкове `explain` — пояснення, яке показується після перевірки. Необов'язкове `hint` — підказка після першої помилки.

| type | обов'язкові поля | перевірка |
|---|---|---|
| `choice` | `options[]` (3–5), `answer` (індекс від 0) | один правильний варіант |
| `multi` | `options[]`, `answer[]` (індекси) | кілька правильних |
| `truefalse` | `items[{text, answer:true/false}]` (3–6) | так / ні |
| `fill` | `text` з пропусками у фігурних дужках: `"з{е}мля, кр{и}ниця"`; варіанти через `\|`: `"{п'ять\|5}"` | вписати слово/букву/число; регістр і пробіли не важливі |
| `number` | `answer` (число) | числова відповідь (можна писати з пробілами: 12 345) |
| `input` | `answer[]` (прийнятні варіанти рядком) | коротка текстова відповідь |
| `match` | `pairs[[ліво, право]]` (3–6) | з'єднати пари (випадаючий список) |
| `order` | `items[]` у ПРАВИЛЬНОМУ порядку (3–7) | учень розставляє по порядку |
| `sort` | `groups{ "Назва групи": [елементи] }` (2–3 групи) | розкласти по групах |
| `text` | `sample` (зразок відповіді), `min`? (мін. символів, типово 20) | письмова робота — перевіряють батьки |
| `checklist` | `items[]` | самоперевірка практичної роботи (мистецтво, фізкультура, технології) |
| `speak` | `text` (що прочитати вголос), `lang`? | читання вголос з озвученням; учень відмічає виконання |

Правила для вправ:
1. У `exercises` мінімум 4 вправи, з них мінімум 3 з автоматичною перевіркою (не `text`/`checklist`/`speak`).
   Для фізкультури, мистецтва, дизайну можна 2 автоматичні + `checklist`.
2. У `homework` 2–4 завдання; хоча б одне з автоматичною перевіркою і хоча б одне `text`
   (письмова робота, яку побачать батьки) — крім фізкультури/мистецтва/дизайну, де замість `text` може бути `checklist`.
3. **Кожну відповідь перевір.** Для математики обчисли результат сам і переконайся, що `answer` правильний.
   Для мови — відповідь має відповідати чинному правопису (2019).
4. Варіанти у `choice`/`multi` — без «усі відповіді правильні», без жартівливих варіантів-заглушок.
5. У `fill` дужки `{}` тільки для пропусків. Якщо потрібен апостроф у відповіді — пиши `'` (звичайний).
6. Не копіюй тексти сучасних авторів (авторське право). Пиши ОРИГІНАЛЬНІ тексти або бери суспільне надбання
   (Шевченко, Франко, Леся Українка, Глібов, Грінченко, Руданський, фольклор: казки, легенди, прислів'я, колядки).
   Переказ міфу/легенди — власними словами.
7. Тексти для читання: 150–400 слів для оповідань, 8–24 рядки для віршів; після тексту — запитання на розуміння
   (`choice`, `truefalse`, `order` подій, `match` герой–вчинок), словникова робота, головна думка.
8. Англійська: інструкції українською, приклади й завдання англійською; словник у блоці `vocab`
   (8–12 слів); хоча б одна вправа `speak`; переклад у відповідях — українською.
9. Уникай зайвих відсилок до «підручника», «класу», «вчителя» — учень удома. Замість «запитай учителя» — «запитай дорослого».
10. Довжина файлу — орієнтовно 4–9 КБ. Без зображень і зовнішніх посилань (крім, за потреби, назв сайтів як тексту).
